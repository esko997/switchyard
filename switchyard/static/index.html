Remote shell

Runs your script with /bin/sh as the unprivileged SSH user on the chosen host. There is no command allowlist, no sudo and no password prompt. Anything you background can outlive the timeout.

Optional. Their device locks are held for the run too. Switchyard cannot work out destinations from the script text.

The script and its output stay on this page and are not stored. Repeating a request ID returns the earlier audit-log entry without running again, and without the output.
